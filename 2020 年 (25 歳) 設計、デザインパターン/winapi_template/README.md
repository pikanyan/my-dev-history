# winapi_template

## 狙い

-   Windows API でウィンドウを生成する最小のコードに関して
    1 ファイルに押し込めず、**責務ごとにクラス分割**し、見通しを良くする練習。

-   後で「別ウィンドウ」を増やすときに、**どこを差し替えるべきか**が見える形にする。

## 注目ポイント

-   エントリーポイントである _tWinMain() が 1 行で完結するインターフェイス
    Python の tkinter のようにシンプルなエントリーポイント

-   責務ごとにクラス分割し、変更箇所が局所化されている

## 構成 (メインウィンドウ 4 点セット)

-   このリポジトリでは「メインウィンドウ表示」を 4 クラスに分割しています。
    -   WndMain: 残りの 3 つのクラスを保持し、管理し易くする。
    -   WndMainRegister: OS に登録する WNDCLASSEX 構造体を設定する責務を持つ。
    -   WndMainCreator: 登録したウィンドウクラスからウィンドウを生成する責務を持つ。
    -   WndMainProcess: fat になりがちなイベントループに関する責務を持つ。

※ 4 つはセットで「メインウィンドウ」を成立させます。

## 別ウィンドウを追加する場合

イベントループを共有しない別のウィンドウを作る場合は、同じ 4 点セットを用意します。

-   `WndAnother`
-   `WndAnotherRegister`
-   `WndAnotherProcess`
-   `WndAnotherCreator`
