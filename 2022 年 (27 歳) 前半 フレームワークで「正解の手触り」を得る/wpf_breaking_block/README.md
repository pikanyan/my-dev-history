# wpf_breaking_block (復元途中)

## 目的

2022 年当時に作成した WPF のブロック崩しを、学習履歴として復元する。

## 現状

-   ビルドは通る
-   UI は表示される
-   ゲーム開始処理（更新ループ/入力/オブジェクト生成）が連携しておらず、未完成

## 詰まった点（原因候補）

-   UserControl 名（Block / Blocks）が混在し、描画対象が不明瞭
-   ブロック群生成ロジックが欠落、またはファイル欠損の可能性
-   デザインパターンの Builder パターンが存在するが、機能しているか不明

## 次にやるなら

-   Block/Blocks の定義を統一
-   Start() を MainWindow の Play ボタンに繋ぐ
-   DispatcherTimer で更新ループを作り、描画と入力を復旧
