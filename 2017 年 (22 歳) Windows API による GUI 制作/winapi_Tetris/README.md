# winapi_Tetris

## 目的

普通のテトリスを、あえて Windows API で実装し、
「ウィンドウ表示 / 描画 / 入力 / タイマー更新」といった基本要素を自分の手でつなぐ練習をする。

## なぜ Windows API だったのか

当時は「仕組みの理解」を重視しており、
フレームワークよりも低レイヤで作ることで、
イベント駆動やウィンドウシステムの流れを体で覚えようとしていた。

## 当時の進め方 (今見ると反省点)

当時は git や GitHub の概念を知らなかったため、
変更履歴の管理を「自分でフォルダを作る」方式で行っていました。

(今なら commit で差分管理します)

## 補足

このフォルダは「当時の学習履歴」を残すことが目的のため、
